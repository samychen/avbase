# 2026-10-20

## 第一百零四圈：Qt 播放器下方时间线的数据是假的

用户报「player_qt 下方编辑器数据是假的」。确认指 `qml/TimelinePanel.qml`
（Shotcut 风格面板，标题 TIMELINE）。

- **假在哪**：`main.cc` 启动时 `timeline.loadDemo()` 铺六条硬编码 clip
  （intro.mp4 / b-roll.mp4 / interview.mp4 / logo.png / music.wav / voice.wav），
  跟打开的文件毫无关系。`+ Clip` 按钮还会继续塞 `clip.mp4`。
- **顺带藏着真 bug**：`duration()` 从 clip 推导 → 项目时长 = 占位数据的 18 秒，
  而 `setPlayhead()` 把播放头 clamp 到 `duration()` → **播到 18 秒后播放头不动**，
  控制栏照常走。30 秒的 test5.mp4 上必现。
- **修法**：`TimelineModel` 只认 MediaInfo。`PlayerBridge` 在 `kPrepared` 调
  `loadFromMedia(name, duration, has_video, has_audio)`：V1 一条视频 + A1 一条
  音频，长度 = 媒体长度；`duration <= 0`（直播）清空面板。
  `duration()` 改为 `project_duration_ > 0 ? project_duration_ : 10`（10 秒下限
  只给空面板，否则 4 秒素材的播放头能跑到 10 秒）。
- **删掉兑现不了的编辑入口**：`+ Clip` / `− Clip` / clip 拖拽 / `selectedRow`。
  背后没有混音器，能拖的 clip 是接了空气的控件。同时删掉随之无调用者的
  `addClip` / `moveClip` / `removeClip` / `clipAt` / `topClipAt` / `loadDemo`。
- **播放头跟随视口**：`Connections { target: timeline; onPlayheadChanged }` 里
  调 `flick.contentX`。否则超过一屏后播放头滚出视野，看起来像时间线停了。

### 两条工程教训

- **占位数据比空面板坏**：空面板一眼看出没做完，假的会被当成真的读（还会
  把 clamp 之类的算术一起污染）。UI 上任何「看起来像数据」的东西都必须来自
  真实现场。
- **C1 顶到 500 行时拆文件，不要压注释凑数**。`player_bridge.cc` 从 496 顶到
  515，按 `renderer_impl.cc` / `renderer_impl_reporting.cc` 的先例把事件那一半
  拆到 `player_bridge_events.cc`（含 `OnEvent` / `ApplyEvent` / `StateName`），
  拆完 399 行。压注释只买到一次，下次再加一行就红。

### Qt 单测怎么接（新踩的坑）

- `tests/unit/qt/` + `qt_unittests` target（Qt Core 即可，**无需屏幕**）。
- **不能走 `avbase_add_unittest()`**：它结尾调 `avbase_configure_target()`，
  带 `-fno-rtti`，moc 生成的 cast 需要 RTTI。自己写 `add_executable` +
  `avbase_configure_abi_definitions()`（只管宏，安全）。
- **AUTOMOC 找不到头文件就静默不生成 moc**，链接期报「missing vtable」，完全
  指不到真因。测试在 `unit/qt/`、头在 `apps/player_qt/`，必须把
  `timeline_model.h` 显式列进目标源。
- `timeline_model.cc` 原 include `<QColor>`（QtGui）却没用到；QtCore-only 的
  测试目标一建就暴露，删掉即可。
- qt_unittests 不在 CI（两个 workflow 都没装 Qt）。本地跑法：
  `cmake -S . -B build/qt-player -DAVBASE_BUILD_TESTS=ON` 然后
  `cmake --build build/qt-player --target qt_unittests`，产物在
  `build/qt-player/bin/qt_unittests`（不是 tests/ 下）。

### 判据

`tests/unit/qt/timeline_model_unittest.cc` 8 条。三条突变都红：
项目时长不落模型（7 红）、视频轨放错车道（2 红）、换文件不清旧轨道（2 红）。
不能只测「load 后有两条 clip」——`duration()` 若同时由 clips 推导，两种实现
对外等价，测试没有鉴别力；所以先删掉 duration() 里那段 clips 循环。

### 实测

test5.mp4（30.03s）：面板 `test5.mp4 · 00:30`，V1/A1 各一条；seek 22s 播放头
可见且跟随；无媒体启动时面板空、写 no media。门禁 inv/fmt/lint 全过
（顺手补了上轮漏格式的 `playback_stats_unittest.cc:99`）。
