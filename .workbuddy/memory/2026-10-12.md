### 新增的一条测试：`ASourceHoldsTheFrameItsLayerIsShowing`

`GlLayerSource` 的类注释声称「保留它上传的那一帧是零拷贝安全的原因」，但此前**没有任何
测试钉住它**。用带 release 回调的原生帧（不可映射）来钉：

- `Publish` 后丢掉本地引用 → 回调未跑；
- `Sync` 后 → 回调仍未跑（图层正在采样这块 surface）；
- `Detach` 后 → 回调跑了。

**为什么必须专门测**：拷贝路线上这句话看不出差别（像素已经在纹理里），所以本机（无导入
后端）任何像素测试都会过，而**有导入后端的机器会采到已释放的 surface**。这跟「有朝向的
代码必须配像素断言」是同一类理由。

### 自己踩的坑（记下来）

- **`git checkout -- <file>` 会把未提交的改动一起回退。** 撤临时探针时手滑用了一次，
  把 `examples/scene_demo.h` 的 L5 改动全清了，靠 `/tmp` 备份恢复。
  **撤探针之前先 `cp` 一份，且只用编辑工具删代码块。**
- **macOS 的 `/usr/bin/grep` 是 BSD grep，BRE 里 `\|` 不是「或」**（那是 GNU 扩展）。
  用它做「查证某符号不存在」会静默给出错误结论。`-E` 加 `|`，或用 Grep 工具。
  这是「PATH 上的 toybox grep shim」那条教训的近亲。
- `TMPDIR` 在 macOS 指向 `/var/folders/...`，不是 `/tmp`。脚本里写死 `/tmp`
  会找不到另一个 shell 建出来的素材。
