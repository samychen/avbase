## 3. 已修关键缺陷（闭环记录）

- **关闭竞态（第二十三/二十四轮）**：`StopSync` 等队列排空而非管线停稳，~50% 播放退出路径
  踩 `~PipelineImpl` CHECK；改等 `!IsRunning()`，崩溃 14/29→0/35。
- **VOD 完成链死锁（第八十轮）**：`VideoRendererImpl::Render` 仅在 present 后 re-arm 解码泵，
  fps-cap 丢帧时泵饿死；修 re-arm 条件（present 或 drop 都 re-arm）+ 去 `MaybeDeliver` 的
  `!end_of_stream_` 门禁；`media_unittests` 393/393。
- **解码器丢包（第三十七轮）**：`DecoderStream` 被 watermark 掐断的批次尾巴永久丢失；批次未
  消费完则 return。
- **corpus 三崩溃（第三十四轮）**：采样格式/声道布局/流量失败三类 `params.is_valid()` 进入方式；
  `AudioParameters` 显式携声道数 + 丢弃不可用音频流。
