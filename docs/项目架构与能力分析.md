## 1. 项目定位（现状版）

**avbase（原 ijkpp）是 ijkplayer 核心的 C++20 重写**，镜像 Chromium base/media 分层，
面向二次开发者的 SDK。2026-10-02 起按 avbase 升级计划执行 Phase 0–4.5：

| 阶段 | 内容 | 状态 |
|---|---|---|
| Phase 0 | 仓库改造（更名 avbase / LICENSE / LGPL 清点 / 行为规范卷 docs/11） | ✅ |
| Phase 1 | 最短出画（M7/M8/M11） | ✅ SDL2 真窗口出画 |
| Phase 2 | 网络流（桥/水位/重试） | 🔶 收口——直播追帧与协议验收 ⬜ |
| Phase 3 | 硬解与零拷贝 | 🔶 解码侧 ✅（VideoToolbox 全链实测）——显示侧零拷贝 ⬜ |
| Phase 4 | 产品化 | 🔶 WSOLA/精确 seek/音·字幕轨切换/fuzz ✅——Qt 门面/corpus/soak ⬜ |

## 2. 架构（实现态）

```
player/   SDK 门面：PlayerImpl/StateMachine/EventHub/SeekController/
          BufferController（三级 HWM）——桩方法只剩轨选/快照等少数
media/    base（值类型/队列/接口）+ filters（解码器/demuxer/WSOLA/音频环/
          文本解码器/retry_data_source）+ renderers（DefaultRendererFactory）
          + legacy/（ffplay 逐行移植，LGPL-2.1 隔离区）
base/     Chromium base 同名同语义子集（expected/callback/task/threading/...）
platform/ ffmpeg（唯一链 FFmpeg）· sdl2（真窗口）· null · videotoolbox（硬解）
          · vaapi · d3d11（后两者解码侧就绪，显示侧零拷贝待硬件验收）
examples/ headless（CI e2e）· play_sdl2（真窗口）· pull_frames（零拷贝验收）
```

依赖铁律由 `tools/check_invariants.py` 强制（7 条结构规则 + C23 列宽棘轮，
2026-10-03 实测 286 行基线只减不增）。

## 3. 能力现状：✅ 可用

| 能力 | 验证方式 |
|---|---|
| 完整播放链路 | demux → decode → A/V 同步（WSOLA/seqlock 时钟）→ render；headless 与 SDL2 真窗口均 kCompleted |
| 网络流基础 | DataSource→AVIOContext 桥（内存/fd/自定义源）、RetryDataSource（重试预算+可中止）、三级 HWM 水位、饥饿信号（per-stream 判决） |
| 精确 seek | `SeekMode::kAccurate`：丢弃窗口 + 呈现帧到达检测 + 超时/取代策略（±1 帧） |
| 运行时音轨切换 | SelectAudioTrack 全链（退役表/排干机制） |
| 字幕文本腿 | kText 轨选择 + TimedText 事件（直播过期丢弃待直播基建） |
| 硬件解码 | VideoToolbox 全链实测（macOS）；VAAPI/D3D11 工厂就绪；NativeBuffer 零拷贝帧 |
| fuzz | libFuzzer 目标 + 确定性 standalone 驱动（demux 输入路径） |
| 诊断 CLI | `ijkpp-inspect probe / decode / sync` |
| 质量门禁 | 393/393（FFmpeg 配置）+ 372/372（no-ffmpeg）全绿（2026-10-03 实测）；CI：strict/ffmpeg/e2e-headless/sdl2-build job |

## 5. 开放决策（到点即决）

LL-HLS 自研 vs 接受 2–3s 延迟（Phase 2 收口时）；M12 原生后端是否启动（出现性能/独占音频硬需求时）；版权主体（首次发布前）；golden 基线锁哪个 ijkplayer 版本（M10 启动时，Q8）。

## 6. 环境备注

宿主为 macOS arm64 / AppleClang 21 / Homebrew FFmpeg 7.1.1 / SDL2 2.32；构建按
preset 分目录（`build/{no-ffmpeg,ffmpeg,debug,asan,tsan,...}`）。GitHub repo 更名
与本地目录 `mv` 待宿主人工执行（内容层已全部 avbase）。GCC `-Wnull-dereference`
在 `thread_unittest.cc` 有 2 处误报，发布构建前豁免（清单 6.3）。
